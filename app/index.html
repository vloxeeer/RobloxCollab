🧩 Плагин для Studio

Установка и настройка плагина

Автоматическая установка

Нажмите кнопку чтобы автоматически установить плагин в папку Roblox Studio.

📖 Пошаговая инструкция

1

Запустите сервер

Перейдите на вкладку "Сервер" и нажмите "Запустить"

2

Установите плагин

Нажмите кнопку "Установить плагин" выше и перезапустите Studio

3

Включите HTTP в Studio

Game Settings → Security → Allow HTTP Requests → ON

4

Откройте плагин

Нажмите кнопку "🔗 Collab" на панели инструментов Studio

5

Создайте комнату

Введите имя, создайте комнату и отправьте код другу

6

Для интернета

Откройте вкладку "Интернет", создайте туннель и отправьте ссылку другу. Друг вводит ссылку в поле "Server URL" в плагине.
