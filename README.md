╔═══════════════════════════════════════════════════╗
║          ИНСТРУКЦИЯ ПО УСТАНОВКЕ                  ║
╠═══════════════════════════════════════════════════╣
║                                                   ║
║  1. Скачай Node.js с https://nodejs.org           ║
║     (нажимай Next → Next → Install)               ║
║                                                   ║
║  2. Скачай проект с GitHub (Download ZIP)         ║
║     и распакуй в любую папку                      ║
║                                                   ║
║  3. Запусти install.bat (двойной клик)            ║
║     Подожди пока всё установится                   ║
║                                                   ║
║  4. Запусти start.bat                             ║
║     Откроется красивое приложение                  ║
║                                                   ║
║  5. В приложении:                                 ║
║     • Нажми "Запустить сервер"                    ║
║     • Нажми "Установить плагин"                   ║
║     • Если нужен интернет → "Открыть туннель"     ║
║                                                   ║
║  6. Открой Roblox Studio:                         ║
║     • Game Settings → Security → HTTP → ON        ║
║     • Нажми кнопку "🔗 Collab" на панели          ║
║     • Создай комнату или присоединись              ║
║                                                   ║
║  7. Отправь код комнаты другу!                    ║
║     (или ссылку туннеля если через интернет)       ║
║                                                   ║
╚═══════════════════════════════════════════════════╝
